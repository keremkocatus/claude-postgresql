# Stage 3 — Loki backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `kind: loki` connections next to the PostgreSQL and Prometheus ones: three read-only tools (`loki_query`,
`loki_labels`, `loki_label_values`) that go through `ToolRuntime`, return compact log lines (stream labels once per
stream, millisecond timestamps, long lines cut and marked) or LogQL metric summaries, say explicitly what was left out
and how to narrow, and never leak credentials, the tenant or internal hosts.

**Architecture:** First the pieces stage 2 wrote for Prometheus but that Loki needs too are moved out of
`backends/prometheus/` (no copies): an `HttpConnection` config base (`config/http_models.py`), the text helpers
(`backends/output.py`), Prometheus-format results and their range summaries (`backends/series.py`,
`backends/summarize.py`, which also render LogQL metric queries), the JSON envelope and scrubbing
(`backends/http/envelope.py`), a timed health probe (`backends/http/health.py`) and the per-call deadline
(`HttpClient.deadline()`). Then `config/loki_models.py` (`LokiConnection`, `tenant` → `X-Scope-OrgID`) joins the
`ConnectionConfig` union and `backends/loki/` adds the API layer (plain-text Loki errors → user-safe errors), the
backend, stream parsing (in a thread, at most `limit` lines built, each clipped to `max_line_bytes`), the log
formatter, tool logic and registration. `ToolRuntime` is unchanged (`kind=` and `truncation_hint=` exist since stage 2).

**Tech Stack:** Python 3.12+, mcp 1.30 (FastMCP), httpx 0.28, pydantic v2; tests with pytest-asyncio (auto mode), respx

## Decisions (where the spec left room)

1. **Loki connections are read-only by construction**, like Prometheus: `mode` is `Literal["read"]` and `mode: write`
   is a config error ("loki connections are read-only: omit mode or set it to read"). The shared rules (url without
   credentials/query/fragment, header checks, timeout 1s–10m, read-only mode) move into an `HttpConnection` base class
   that `PrometheusConnection` and `LokiConnection` both extend; the error texts stay as they were.
2. **Tenant.** `tenant: ${LOKI_TENANT}` (optional, `SecretStr`) is sent as `X-Scope-OrgID` on every request.
   `X-Scope-OrgID` under `headers` is **refused** ("headers: X-Scope-OrgID cannot be set here; use tenant") so there is
   one source. The value must look like a Loki tenant ID (letters, digits, `!-_.*'()`, at most 150 characters; several
   joined with `|` for a cross-tenant query); numbers in YAML become text; messages never echo it. `check-config`
   prints `tenant: yes|no`, never the value.
3. **Tool signatures.** `loki_query(connection, logql, start?, end?, limit?, direction?, step?)`,
   `loki_labels(connection, selector?, start?, end?)`, `loki_label_values(connection, label, selector?, start?, end?)`.
   Two additions to spec §6.4, both optional: `step` (metric queries need a resolution; same rules as
   `prom_query_range`) and `selector` (Loki's `query` parameter on the label endpoints: "values of `pod` for
   `{app="api"}`" is the common question). `direction` is `Literal["backward", "forward"]`, so the JSON schema lists
   the two values; default `backward` (newest first).
4. **One endpoint for `loki_query`.** Always `POST /loki/api/v1/query_range` (form body: LogQL stays out of URLs and
   proxy logs, no URL length limit; verified on Loki 3.7). The answer's `resultType` decides the format: `streams` → log
   lines, `matrix` → per-series summaries via the shared `format_matrix`. Loki's instant endpoint refuses log queries,
   so a single path is simpler and a metric query over a window is what an investigation needs. Any other type is a
   clear error.
5. **Limits** (`connections.<name>.limits`): `max_lines: 500` (the highest `limit`; 1–5000, Loki's own default
   `max_entries_limit_per_query`), `max_line_bytes: 2048` (64–65536), `max_range: 24h` (≥ 1m), plus the stage 2 caps:
   `max_series: 100`, `max_points: 1000` (metric queries), `max_values: 500` (label lists), `max_query_length: 20000`,
   `max_response_bytes: 65536`, `max_body_bytes: 8 MiB`. The default `limit` is **100** (or `max_lines` if lower): 100
   typical lines fit the 64 KiB response; 500 often do not. A `limit` outside 1..`max_lines` is **refused**, not
   silently lowered (same rule as an oversized `step` in stage 2). Window, `limit` and `step` are all checked before any
   request.
6. **Log output.** Header: `N log lines in M streams from <start> to <end>, newest first (times are UTC).` Labels that
   every stream shares are printed once (`Labels on every stream: {...}`); each stream then gets one header with only
   its own labels and its line count, followed by its lines as `  HH:MM:SS.mmm <text>` (`MM-DDTHH:MM:SS.mmm` when the
   window crosses a day). Streams are ordered by their first line (newest first for `backward`, oldest first for
   `forward`); lines keep Loki's order. Lines of a multi-line entry (stack traces) are indented under the text, so a log
   line cannot fake a stream header. A line longer than `max_line_bytes` is cut on a character boundary and ends with
   `… [cut: N bytes]`. Stream headers are cut to 1 KiB (labels from `| json` can be many). Log lines are user data:
   never scrubbed or redacted. Labels Loki adds itself (`service_name`, `detected_level`) are shown like any other.
7. **Notes** (all inside the 2 KiB note reserve, so the runtime clamp never cuts them): `[Showing X of Y log lines:
   the response size limit was reached. <how to narrow>]` when the budget runs out (whole lines only);
   `[Loki stopped at the limit of N lines: older|newer lines in this window were not returned. Narrow … , or pass a
   higher limit (at most max_lines).]` when Loki returned `limit` lines; `[K lines were longer than this connection's
   line limit and were cut …]`; at most 5 server warnings (`Notes from Loki:`).
8. **Errors.** Loki answers a bad query with HTTP 400 and **plain text** (`parse error at line 1, col 11: …`), which can
   echo the query: shown as `Loki rejected the query: <text>` after `scrub_server_text` (linear patterns, input cut
   first). A JSON body's `error`/`message` is read the same way. HTTP 401 with exactly `no org id` → "this Loki server
   is multi-tenant and needs a tenant. Ask the administrator to set tenant on the connection." HTTP 504 (Loki's query
   timeout) → `BackendTimeoutError` (audit `timeout`). 401/403, 404, 429, 3xx, 5xx and HTML pages get the stage 2 fixed
   wording; details go to the log.
9. **Deadline and timeouts.** Loki has no per-request timeout parameter (its `query_timeout` is per tenant on the
   server), so only the client side applies: each call runs under one `HttpClient.deadline()` of `timeout` + 5s
   (`connection_health` sends two requests under it).
10. **Health.** `connection_health` first lists the labels of the last minute (that request needs working credentials
    and tenant; buildinfo needs neither), then reads the version from `/loki/api/v1/status/buildinfo` (bare JSON, no
    envelope): `Loki 3.7.9`, or `Loki API` when buildinfo is missing or fails.
11. **Shapes.** Empty label lists come back as `{"status":"success"}` without `data` (treated as empty). A third
    element on a stream value (structured metadata, only with `X-Loki-Response-Encoding-Flags`, which is not sent) is
    ignored. Stream parsing builds at most `limit` lines and only counts the rest (a server that ignores `limit` cannot
    blow up memory past `max_body_bytes`).
12. **Shared code instead of copies.** `output.py`, `series.py`, `summarize.py`, `http/envelope.py`, `http/health.py`
    and `HttpClient.deadline()` come out of the Prometheus package; Prometheus behaviour and texts are unchanged except
    one: an unreadable Prometheus result now says "The server returned a result in a shape Ratatoskr cannot read."
    (the shared parser no longer names Prometheus). `truncation_note` needs `hint=` and `with_notes` needs `source=`,
    so no Prometheus wording can leak into Loki answers by default.
13. **Integration container.** `grafana/loki:3.7.9`, single binary, filesystem storage, `auth_enabled: true` (so the
    tenant is really tested), `analytics.reporting_enabled: false` (no usage reports to grafana.com), port bound to
    127.0.0.1. Sample logs go in through the push API for tenant `team-a`.

## Risks and notes

- **LogQL is not restricted.** Anyone with read access can run any query over the tenant's logs; the risk is load.
  Ratatoskr caps the window (24h), lines, points, what it reads and returns, and the deadline; operators keep Loki's
  per-tenant limits (`query_timeout`, `max_query_length`, `max_query_series`, `max_entries_limit_per_query`) and give
  each connection a tenant/credential that only sees what its users may see. Documented in the README.
- **Secrets inside log lines are shown.** Log lines are user data (repo rule), so `password=…` written into a log is
  returned as is. Only error texts, logs and the audit `query_text` are masked. Documented.
- **POST on query_range.** Loki's docs describe `GET`; the server accepts `POST` (verified on 3.7 and used by Loki's
  own clients for long queries). A gateway that only forwards `GET` would answer 405, which shows as "Loki rejected the
  request (HTTP 405): …". If that shows up in practice, add a one-time `GET` fallback on 405; not built now (YAGNI).
- **Older Loki.** The `query` parameter of the label endpoints is not honoured by old servers (they list everything);
  the README says the label tools' `selector` needs a server that supports it. Only Loki 3.7 is tested.
- **Body cap vs. very long lines.** 500 lines of 100 KB each exceed 8 MiB: the call is refused with "lower limit or
  narrow the query" rather than returning cut lines. `max_body_bytes` can be raised per connection.
- **Refactor of stage 2 code.** Moving modules touches Prometheus imports and five Prometheus test files; Tasks 1–3
  keep the whole unit suite green after each step, so a mistake shows immediately.
- **Clock.** Relative times use the server's clock (UTC); Loki may align metric steps past `end` (observed: the last
  point is a few seconds after `end`); harmless.
- **Pulling the image.** The first integration run pulls `grafana/loki:3.7.9` from Docker Hub; everything else stays on
  127.0.0.1.

```python
"""Config model of a ``kind: prometheus`` connection (spec 4 and 6.3)."""

from __future__ import annotations

from datetime import timedelta
from typing import Any, ClassVar, Literal

from pydantic import BaseModel, ConfigDict, Field, field_validator

from ratatoskr.config.http_models import HttpConnection
from ratatoskr.config.shared import DEFAULT_MAX_RESPONSE_BYTES, check_max_range, duration_value

# Prometheus refuses range queries with more than 11,000 points per series.
PROMETHEUS_MAX_POINTS = 11_000


class PrometheusLimits(BaseModel):
    model_config = ConfigDict(extra="forbid")

    max_series: int = Field(default=100, ge=1, le=10_000)  # series (and alerts) shown per response
    max_values: int = Field(default=500, ge=1, le=100_000)  # metric names / label values shown per response
    max_points: int = Field(default=1000, ge=10, le=PROMETHEUS_MAX_POINTS)  # per series in prom_query_range
    max_range: timedelta = timedelta(days=31)
    max_query_length: int = Field(default=20_000, ge=1)
    max_response_bytes: int = Field(default=DEFAULT_MAX_RESPONSE_BYTES, ge=1024)
    max_body_bytes: int = Field(default=8 * 1024 * 1024, ge=64 * 1024)  # read from Prometheus per request

    @field_validator("max_range", mode="before")
    @classmethod
    def _parse_max_range(cls, value: Any) -> timedelta:
        return duration_value(value)

    @field_validator("max_range")
    @classmethod
    def _check_max_range(cls, value: timedelta) -> timedelta:
        return check_max_range(value)


class PrometheusConnection(HttpConnection):
    """url, auth, headers, tls, timeout and the read-only mode come from :class:`HttpConnection`."""

    KIND: ClassVar[str] = "prometheus"

    kind: Literal["prometheus"]
    limits: PrometheusLimits = PrometheusLimits()
```

```python
"""Compact text for an LLM reader, shared by the HTTP backends: the byte-budgeted block writer, truncation notes,
server notes and errors shown inside a successful answer."""

from __future__ import annotations

from collections.abc import Sequence
from typing import Any

from ratatoskr.observability.redact import redact

MAX_NOTES = 5  # server notes (warnings, infos) shown per answer; the rest are counted
# Room kept after the budgeted blocks for the truncation note, one side note (SIDE_NOTE_BYTES) and the
# server notes (at most MAX_NOTES of NOTE_BYTES each, about 1.3 KB), so the clamp never cuts them.
NOTE_RESERVE_BYTES = 2048
NOTE_BYTES = 240
SIDE_NOTE_BYTES = 360


class BlockWriter:
    """Collects blocks until the byte budget is spent. The first block is always kept."""

    def __init__(self, budget: int) -> None:
        self._budget = budget
        self._blocks: list[str] = []
        self._size = 0

    @property
    def kept(self) -> int:
        return len(self._blocks)

    @property
    def remaining(self) -> int:
        return max(0, self._budget - self._size)

    def add(self, block: str) -> bool:
        size = len(block.encode("utf-8")) + 1
        if self._blocks and self._size + size > self._budget:
            return False
        self._blocks.append(block)
        self._size += size
        return True

    def text(self) -> str:
        return "\n".join(self._blocks)


def response_budget(max_response_bytes: int) -> int:
    return max(512, max_response_bytes - NOTE_RESERVE_BYTES)


def truncation_note(shown: int, total: int, limit: int, *, unit: str = "series", hint: str) -> str:
    """Empty when everything is shown; otherwise says how many were left out, why, and how to narrow."""
    if shown >= total:
        return ""
    reason = f"the limit is {limit}" if shown >= limit else "the response size limit was reached"
    return f"\n\n[Showing {shown} of {total} {unit}: {reason}. {hint}]"


def with_notes(text: str, notes: Sequence[str], *, source: str, omitted: int = 0) -> str:
    """*text* with the first MAX_NOTES server notes, each cut to NOTE_BYTES, and how many more there were."""
    if not notes and not omitted:
        return text
    lines = [f"- {clip_bytes(note, NOTE_BYTES)}" for note in notes[:MAX_NOTES]]
    more = omitted + max(0, len(notes) - MAX_NOTES)
    if more:
        lines.append(f"- ... and {more} more")
    return text + f"\n\nNotes from {source}:\n" + "\n".join(lines)


def error_note(prefix: str, error: BaseException) -> str:
    """An error shown inside a successful answer (an optional part failed): redacted like any error text,
    and short enough to fit the note reserve."""
    return clip_bytes(f"{prefix}: {redact(str(error))}", SIDE_NOTE_BYTES)


def clip_bytes(text: str, limit: int) -> str:
    """*text* cut to at most *limit* UTF-8 bytes (with an ellipsis when cut)."""
    encoded = text.encode("utf-8")
    if len(encoded) <= limit:
        return text
    return encoded[: max(0, limit - 3)].decode("utf-8", errors="ignore") + "…"


def cell(value: Any, limit: int = 300) -> str:
    """One Markdown table cell: pipes escaped, line breaks flattened, long text cut."""
    text = str(value).replace("\\", "\\\\").replace("|", r"\|").replace("\r", "").replace("\n", " ")
    return text if len(text) <= limit else text[:limit] + "…"
```

```python
"""The JSON envelope Prometheus and Loki share (``{"status": "success", "data": ..., "warnings": [...]}``) and the
scrubbing every server message goes through before it may be shown."""

from __future__ import annotations

import asyncio
from collections.abc import Callable, Iterable
from dataclasses import dataclass, field
from typing import Any

from ratatoskr.backends.http.client import parse_json
from ratatoskr.backends.http.scrub import scrub_upstream_text
from ratatoskr.backends.output import MAX_NOTES
from ratatoskr.observability.redact import redact


@dataclass(frozen=True)
class ApiResult:
    data: Any
    notes: list[str] = field(default_factory=list)  # the first scrubbed warnings and infos from the server
    omitted_notes: int = 0  # further warnings and infos, counted but not shown


def scrub_server_text(text: str, *, hosts: Iterable[str]) -> str:
    """Server text (errors, warnings, rule errors) as it may be shown: no addresses, no secrets."""
    return redact(scrub_upstream_text(text, hosts=hosts))


async def decode_json(body: bytes) -> Any | None:
    """The decoded body (None when it is not JSON), off the event loop. The C decoder holds the GIL, so the loop
    still stalls (~20 ms per MiB); ``max_body_bytes`` bounds that."""
    return await asyncio.to_thread(parse_json, body)


def success_result(status: int, payload: Any, scrub: Callable[[str], str]) -> ApiResult | None:
    """The data and the first MAX_NOTES scrubbed warnings and infos of a successful answer; None for any other."""
    if status != 200 or not isinstance(payload, dict) or payload.get("status") != "success":
        return None
    found: list[tuple[str, Any]] = []
    for key, label in (("warnings", "warning"), ("infos", "info")):
        values = payload.get(key)
        if isinstance(values, list):
            found += [(label, value) for value in values]
    notes = [f"{label}: {scrub(str(value))}" for label, value in found[:MAX_NOTES]]
    return ApiResult(data=payload.get("data"), notes=notes, omitted_notes=len(found) - len(notes))
```

```python
        self._hosts = frozenset(hosts)
        # Prometheus' own evaluation timeout; the HTTP deadline is a little longer so this one answers first.
        self._eval_timeout = f"{max(1, int(client.timeout))}s"

    def scrub(self, text: str) -> str:
        """Server text (errors, warnings, rule errors) as it may be shown: no addresses, no secrets."""
        return scrub_server_text(text, hosts=self._hosts)

    async def query(self, promql: str, time: str) -> ApiResult:
        form = {"query": promql, "time": time, "timeout": self._eval_timeout}
        return await self._call("POST", "/api/v1/query", form=form, hint=SERIES_HINT)

    async def query_range(self, promql: str, start: str, end: str, step: str) -> ApiResult:
        form = {"query": promql, "start": start, "end": end, "step": step, "timeout": self._eval_timeout}
        return await self._call("POST", "/api/v1/query_range", form=form, hint=SERIES_HINT)

    async def label_values(self, label: str, *, match: str | None, start: str, end: str) -> ApiResult:
        params: dict[str, str | list[str]] = {"start": start, "end": end}
        if match is not None:
            params["match[]"] = [match]
        path = f"/api/v1/label/{quote(label, safe='')}/values"
        return await self._call("GET", path, params=params, hint=VALUES_HINT)

    async def metadata(self) -> ApiResult:
        return await self._call("GET", "/api/v1/metadata", params={"limit_per_metric": "1"})

    async def alerts(self) -> ApiResult:
        return await self._call("GET", "/api/v1/alerts")

    async def rules(self) -> ApiResult:
        return await self._call("GET", "/api/v1/rules")

    async def buildinfo(self) -> ApiResult:
        return await self._call("GET", "/api/v1/status/buildinfo")

    async def _call(
        self,
        method: Literal["GET", "POST"],
        path: str,
        *,
        params: Fields | None = None,
        form: Fields | None = None,
        hint: str = "",
    ) -> ApiResult:
        reply = await self._client.request(method, path, params=params, form=form, too_large_hint=hint)
        payload = await decode_json(reply.body)
        result = success_result(reply.status, payload, self.scrub)
        if result is not None:
            return result
        raise self._error(reply, payload, path)

    def _error(self, reply: HttpReply, payload: Any, path: str) -> BackendError:
        if isinstance(payload, dict) and payload.get("status") == "error":
            raw_type = str(payload.get("errorType") or "error")
            error_type = raw_type if raw_type in _KNOWN_ERROR_TYPES else self.scrub(raw_type)[:ERROR_TYPE_CHARS]
            message = self.scrub(str(payload.get("error") or "no details"))
            if error_type in _TIMEOUT_ERROR_TYPES:
                return BackendTimeoutError(
                    f"Prometheus stopped the query ({error_type}): {message}. "
                    "Shorten the range, raise the step, or select fewer series."
                )
            return BackendQueryError(f"Prometheus error ({error_type}): {message}")
        logger.warning(
            "connection %s answered HTTP %d on %s without an API body: %r",
            self._connection,
            reply.status,
            path,
            reply.body[:200],
        )
        if reply.status == 200:
            return BackendUnavailableError(
                f"Connection '{self._connection}' did not answer like a Prometheus API; check that its url is the "
                "API root. Details are in the server log."
            )
        return status_error(self._connection, reply.status)
```

```python
"""Prometheus backend: one httpx client per connection, opened lazily by the registry and closed on shutdown.

Opening creates the client only (no request), so an unreachable server shows up on the first tool call as a
user-safe "unavailable" error rather than at startup.
"""

from __future__ import annotations

import contextlib
from collections.abc import Callable
from datetime import datetime
from typing import Any, ClassVar

from ratatoskr.backends.base import ConnectionInfo, HealthResult
from ratatoskr.backends.http.client import EndpointNotFoundError, HttpClient
from ratatoskr.backends.http.health import timed_health
from ratatoskr.backends.prometheus.api import PrometheusApi
from ratatoskr.backends.timeparse import unix_seconds, utc_now
from ratatoskr.config.prometheus_models import PrometheusConnection, PrometheusLimits


class PrometheusBackend:
    kind: ClassVar[str] = "prometheus"

    def __init__(self, name: str, config: PrometheusConnection, *, clock: Callable[[], datetime] = utc_now) -> None:
        self.name = name
        self.config = config
        self._clock = clock
        self._client = HttpClient(
            name,
            base_url=str(config.url),
            auth=config.auth,
            headers=config.headers,
            tls=config.tls,
            timeout=config.timeout.total_seconds(),
            max_body_bytes=config.limits.max_body_bytes,
        )
        host = config.url.host or ""
        self.api = PrometheusApi(name, self._client, hosts={host, f"{host}:{config.url.port}"})

    @property
    def limits(self) -> PrometheusLimits:
        return self.config.limits

    @property
    def is_open(self) -> bool:
        return self._client.is_open

    def now(self) -> datetime:
        return self._clock()

    async def open(self) -> None:
        await self._client.open()

    def deadline(self) -> contextlib.AbstractAsyncContextManager[None]:
        """One deadline for a whole tool call, which may send several requests (see ``HttpClient.deadline``)."""
        return self._client.deadline()

    async def close(self) -> None:
        await self._client.aclose()

    async def health(self) -> HealthResult:
        return await timed_health(self.name, self._version)

    async def _version(self) -> str:
        """``Prometheus <version>`` from buildinfo; servers without that endpoint are probed with a query."""
        try:
            result = await self.api.buildinfo()
        except EndpointNotFoundError:
            await self.api.query("1", unix_seconds(self.now()))
            return "Prometheus API"
        version = _field(result.data, "version")
        return f"Prometheus {version}" if version else "Prometheus API"

    def describe(self) -> ConnectionInfo:
        return ConnectionInfo(
            name=self.name, kind=self.kind, description=self.config.description, mode=self.config.mode
        )


def _field(data: Any, key: str) -> str | None:
    value = data.get(key) if isinstance(data, dict) else None
    return str(value) if value else None
```

```python
"""Config model of a ``kind: loki`` connection (spec 4 and 6.4)."""

from __future__ import annotations

import re
from datetime import timedelta
from typing import Any, ClassVar, Literal

from pydantic import BaseModel, ConfigDict, Field, SecretStr, field_validator

from ratatoskr.config.http_models import HttpConnection
from ratatoskr.config.shared import DEFAULT_MAX_RESPONSE_BYTES, check_max_range, duration_value

TENANT_HEADER = "X-Scope-OrgID"
# Loki tenant IDs: letters, digits and !-_.*'() (at most 150 each); '|' joins several for multi-tenant queries.
_TENANT_RE = re.compile(r"^[A-Za-z0-9!_.*'()-]{1,150}(?:\|[A-Za-z0-9!_.*'()-]{1,150})*$")
# Loki refuses more points per series than this, like Prometheus.
LOKI_MAX_POINTS = 11_000
# Loki's own default for max_entries_limit_per_query; a higher limit would be refused by the server.
LOKI_MAX_LINES = 5000


class LokiLimits(BaseModel):
    model_config = ConfigDict(extra="forbid")

    max_lines: int = Field(default=500, ge=1, le=LOKI_MAX_LINES)  # log lines per loki_query (the highest limit)
    max_line_bytes: int = Field(default=2048, ge=64, le=65_536)  # each log line is cut to this many bytes
    max_series: int = Field(default=100, ge=1, le=10_000)  # series shown for a metric query
    max_values: int = Field(default=500, ge=1, le=100_000)  # label names / values shown per response
    max_points: int = Field(default=1000, ge=10, le=LOKI_MAX_POINTS)  # per series in a metric query
    max_range: timedelta = timedelta(hours=24)
    max_query_length: int = Field(default=20_000, ge=1)
    max_response_bytes: int = Field(default=DEFAULT_MAX_RESPONSE_BYTES, ge=1024)
    max_body_bytes: int = Field(default=8 * 1024 * 1024, ge=64 * 1024)  # read from Loki per request

    @field_validator("max_range", mode="before")
    @classmethod
    def _parse_max_range(cls, value: Any) -> timedelta:
        return duration_value(value)

    @field_validator("max_range")
    @classmethod
    def _check_max_range(cls, value: timedelta) -> timedelta:
        return check_max_range(value)


class LokiConnection(HttpConnection):
    """url, auth, headers, tls, timeout and the read-only mode come from :class:`HttpConnection`.

    ``tenant`` is sent as ``X-Scope-OrgID``; that header cannot also be set under ``headers`` (one source only).
    """

    KIND: ClassVar[str] = "loki"

    kind: Literal["loki"]
    tenant: SecretStr | None = None
    limits: LokiLimits = LokiLimits()

    @field_validator("tenant", mode="before")
    @classmethod
    def _stringify_tenant(cls, value: Any) -> Any:
        # YAML reads `tenant: 42` as a number; tenant IDs are text.
        return str(value) if isinstance(value, int | float) and not isinstance(value, bool) else value

    @field_validator("tenant")
    @classmethod
    def _check_tenant(cls, value: SecretStr | None) -> SecretStr | None:
        if value is not None and not _TENANT_RE.match(value.get_secret_value()):
            raise ValueError(
                "tenant must be a Loki tenant ID: letters, digits and !-_.*'() (at most 150 characters), "
                "several joined with |"
            )
        return value

    @field_validator("headers")
    @classmethod
    def _refuse_tenant_header(cls, value: dict[str, SecretStr]) -> dict[str, SecretStr]:
        if any(name.lower() == TENANT_HEADER.lower() for name in value):
            raise ValueError(f"headers: {TENANT_HEADER} cannot be set here; use tenant")
        return value
```

Create `src/ratatoskr/backends/loki/api.py`:

```python
"""The Loki HTTP API endpoints Ratatoskr reads, and the mapping of Loki's error answers to user-safe errors.

Only read endpoints are called: query_range, labels, label values and buildinfo. Push, tail, delete, rules and the
admin endpoints are not reachable through this module. Loki answers a bad query with plain text (``parse error at
line 1, col 11: ...``) that can echo the query; it is shown after :func:`scrub_server_text` removes addresses and
masks secrets. Answers without a usable message (401/403, 404, 429, 3xx, 5xx, HTML pages) get fixed wording, and
the details go to the log.
"""

from __future__ import annotations

import logging
from collections.abc import Iterable
from typing import Any, Literal
from urllib.parse import quote

from ratatoskr.backends.errors import BackendError, BackendQueryError, BackendTimeoutError, BackendUnavailableError
from ratatoskr.backends.http.client import Fields, HttpClient, HttpReply, status_error
from ratatoskr.backends.http.envelope import ApiResult, decode_json, scrub_server_text, success_result
from ratatoskr.backends.http.scrub import SCRUB_INPUT_CHARS
from ratatoskr.backends.limits import clip_input

SOURCE = "Loki"  # names the server in "Notes from ..."
LINES_HINT = 'Narrow the query: a shorter time range, more label matchers, a |= "text" line filter, or a lower limit.'
SERIES_HINT = "Select fewer series with label matchers, or aggregate (sum by (...), topk(10, ...))."
VALUES_HINT = 'Pass a stream selector such as {app="api"}, or a shorter time range.'
NO_ORG_ID = "no org id"  # Loki's whole answer (HTTP 401) when a multi-tenant server gets no X-Scope-OrgID
_ERROR_BYTES = 4 * SCRUB_INPUT_CHARS  # enough UTF-8 for the characters the scrubber looks at
_FIXED_WORDING = frozenset({401, 403, 404, 429})  # status_error explains these better than the server's text

Direction = Literal["backward", "forward"]

logger = logging.getLogger("ratatoskr.backends.loki")


class LokiApi:
    def __init__(self, connection: str, client: HttpClient, *, hosts: Iterable[str]) -> None:
        self._connection = connection
        self._client = client
        self._hosts = frozenset(hosts)

    def scrub(self, text: str) -> str:
        """Server text (errors, warnings) as it may be shown: no addresses, no secrets."""
        return scrub_server_text(text, hosts=self._hosts)

    async def query_range(
        self, logql: str, *, start: str, end: str, limit: int, direction: Direction, step: str
    ) -> ApiResult:
        """A log query (``streams``) or a metric query (``matrix``) over a window; POST keeps LogQL out of URLs."""
        form = {"query": logql, "start": start, "end": end, "limit": str(limit), "direction": direction, "step": step}
        return await self._call("POST", "/loki/api/v1/query_range", form=form, hint=LINES_HINT)

    async def labels(self, *, selector: str | None, start: str, end: str) -> ApiResult:
        return await self._call("GET", "/loki/api/v1/labels", params=_window(selector, start, end), hint=VALUES_HINT)

    async def label_values(self, label: str, *, selector: str | None, start: str, end: str) -> ApiResult:
        path = f"/loki/api/v1/label/{quote(label, safe='')}/values"
        return await self._call("GET", path, params=_window(selector, start, end), hint=VALUES_HINT)

    async def buildinfo(self) -> str | None:
        """The server version; Loki answers this endpoint without the success envelope."""
        path = "/loki/api/v1/status/buildinfo"
        reply = await self._client.request("GET", path)
        payload = await decode_json(reply.body)
        if reply.status == 200 and isinstance(payload, dict):
            version = payload.get("version")
            return clip_input(str(version), 40) if version else None
        raise self._error(reply, payload, path)

    async def _call(
        self,
        method: Literal["GET", "POST"],
        path: str,
        *,
        params: Fields | None = None,
        form: Fields | None = None,
        hint: str = "",
    ) -> ApiResult:
        reply = await self._client.request(method, path, params=params, form=form, too_large_hint=hint)
        payload = await decode_json(reply.body)
        result = success_result(reply.status, payload, self.scrub)
        if result is not None:
            return result
        raise self._error(reply, payload, path)

    def _error(self, reply: HttpReply, payload: Any, path: str) -> BackendError:
        status = reply.status
        message = _server_message(reply.body, payload)
        if status == 401 and message == NO_ORG_ID:
            return BackendQueryError(
                f"Connection '{self._connection}' refused the request (HTTP 401): this Loki server is multi-tenant "
                "and needs a tenant. Ask the administrator to set tenant on the connection."
            )
        if status == 504:
            return BackendTimeoutError(
                "Loki stopped the query (HTTP 504, timeout). Shorten the time range, add label matchers or a "
                '|= "text" line filter.'
            )
        if 400 <= status < 500 and status not in _FIXED_WORDING and message:
            prefix = "Loki rejected the query" if status == 400 else f"Loki rejected the request (HTTP {status})"
            return BackendQueryError(f"{prefix}: {self.scrub(message)}")
        logger.warning(
            "connection %s answered HTTP %d on %s without a usable message: %r",
            self._connection,
            status,
            path,
            reply.body[:200],
        )
        if status == 200:
            return BackendUnavailableError(
                f"Connection '{self._connection}' did not answer like a Loki API; check that its url is the Loki "
                "root (requests go to <url>/loki/api/v1/...). Details are in the server log."
            )
        return status_error(self._connection, status)


def _window(selector: str | None, start: str, end: str) -> dict[str, str]:
    params = {"start": start, "end": end}
    if selector is not None:
        params["query"] = selector
    return params


def _server_message(body: bytes, payload: Any) -> str | None:
    """The error text of an answer: ``error`` or ``message`` of a JSON body, or a plain-text body. None for HTML
    (a proxy or login page), other JSON and empty bodies."""
    if isinstance(payload, dict):
        found = payload.get("error") or payload.get("message")
        return str(found) if found else None
    if payload is not None:
        return None
    text = body[:_ERROR_BYTES].decode("utf-8", errors="replace").strip()
    return text if text and not text.startswith("<") else None
```

```python
"""Loki backend: one httpx client per connection, opened lazily by the registry and closed on shutdown.

Opening creates the client only (no request), so an unreachable server shows up on the first tool call as a
user-safe "unavailable" error rather than at startup. ``tenant`` becomes the ``X-Scope-OrgID`` header of every
request.
"""

from __future__ import annotations

import contextlib
from collections.abc import Callable
from datetime import datetime, timedelta
from typing import ClassVar

from pydantic import SecretStr

from ratatoskr.backends.base import ConnectionInfo, HealthResult
from ratatoskr.backends.errors import BackendError
from ratatoskr.backends.http.client import HttpClient
from ratatoskr.backends.http.health import timed_health
from ratatoskr.backends.loki.api import LokiApi
from ratatoskr.backends.timeparse import unix_seconds, utc_now
from ratatoskr.config.loki_models import TENANT_HEADER, LokiConnection, LokiLimits

HEALTH_WINDOW = timedelta(minutes=1)


class LokiBackend:
    kind: ClassVar[str] = "loki"

    def __init__(self, name: str, config: LokiConnection, *, clock: Callable[[], datetime] = utc_now) -> None:
        self.name = name
        self.config = config
        self._clock = clock
        headers: dict[str, SecretStr] = dict(config.headers)
        if config.tenant is not None:
            headers[TENANT_HEADER] = config.tenant
        self._client = HttpClient(
            name,
            base_url=str(config.url),
            auth=config.auth,
            headers=headers,
            tls=config.tls,
            timeout=config.timeout.total_seconds(),
            max_body_bytes=config.limits.max_body_bytes,
        )
        host = config.url.host or ""
        self.api = LokiApi(name, self._client, hosts={host, f"{host}:{config.url.port}"})

    @property
    def limits(self) -> LokiLimits:
        return self.config.limits

    @property
    def is_open(self) -> bool:
        return self._client.is_open

    def now(self) -> datetime:
        return self._clock()

    async def open(self) -> None:
        await self._client.open()

    def deadline(self) -> contextlib.AbstractAsyncContextManager[None]:
        """One deadline for a whole tool call (see ``HttpClient.deadline``)."""
        return self._client.deadline()

    async def close(self) -> None:
        await self._client.aclose()

    async def health(self) -> HealthResult:
        return await timed_health(self.name, self._version)

    async def _version(self) -> str:
        """The labels of the last minute prove that the credentials and the tenant work (buildinfo needs neither);
        buildinfo then adds the version when the server offers it."""
        now = self.now()
        await self.api.labels(selector=None, start=unix_seconds(now - HEALTH_WINDOW), end=unix_seconds(now))
        try:
            version = await self.api.buildinfo()
        except BackendError:
            return "Loki API"
        return f"Loki {version}" if version else "Loki API"

    def describe(self) -> ConnectionInfo:
        return ConnectionInfo(
            name=self.name, kind=self.kind, description=self.config.description, mode=self.config.mode
        )
```

```python
"""Parse Loki log query results (``resultType: streams``): stream labels and their lines, each line clipped to
``max_line_bytes`` while it is built. Log lines are the user's data: they are cut, never scrubbed or redacted."""

from __future__ import annotations

from dataclasses import dataclass
from typing import Any

from ratatoskr.backends.errors import BackendQueryError


@dataclass(frozen=True)
class LogLine:
    ns: int  # unix time in nanoseconds, as Loki sends it
    text: str  # at most max_line_bytes of UTF-8
    size: int = 0  # the full size in bytes when the line was cut; 0 when it is whole

    @property
    def cut(self) -> bool:
        return self.size > 0


@dataclass(frozen=True)
class Stream:
    labels: dict[str, str]
    lines: list[LogLine]


@dataclass(frozen=True)
class StreamsResult:
    streams: list[Stream]  # only streams with at least one built line
    omitted: int = 0  # lines beyond max_lines in the answer: counted, never built

    @property
    def built(self) -> int:
        return sum(len(stream.lines) for stream in self.streams)

    @property
    def total(self) -> int:
        return self.built + self.omitted


def parse_streams(data: Any, *, max_lines: int, max_line_bytes: int) -> StreamsResult:
    """Build at most *max_lines* lines in the server's order (Loki already stops at the request's limit); later
    ones are only counted. CPU-bound on large answers: callers run it off the event loop."""
    try:
        return _parse(data["result"], max_lines, max_line_bytes)
    except (KeyError, IndexError, TypeError, ValueError):
        raise BackendQueryError("Loki returned log lines in a shape Ratatoskr cannot read.") from None


def _parse(raw: Any, max_lines: int, max_line_bytes: int) -> StreamsResult:
    if not isinstance(raw, list):
        raise TypeError("result")
    room = max_lines
    streams: list[Stream] = []
    omitted = 0
    for item in raw:
        values = item.get("values") or []
        if not isinstance(values, list):
            raise TypeError("values")
        kept = values[:room]
        omitted += len(values) - len(kept)
        room -= len(kept)
        if kept:
            labels = {str(key): str(value) for key, value in (item.get("stream") or {}).items()}
            streams.append(Stream(labels=labels, lines=[_line(value, max_line_bytes) for value in kept]))
    return StreamsResult(streams=streams, omitted=omitted)


def _line(value: Any, max_line_bytes: int) -> LogLine:
    ns, text = int(value[0]), str(value[1])  # a third element (structured metadata) is not shown
    clipped, size = clip_line(text, max_line_bytes)
    return LogLine(ns=ns, text=clipped, size=size)


def clip_line(text: str, max_bytes: int) -> tuple[str, int]:
    """*text* cut to at most *max_bytes* UTF-8 bytes (never inside a character), and its full size when cut."""
    if len(text) * 4 <= max_bytes:  # no character takes more than 4 bytes: it fits without encoding
        return text, 0
    encoded = text.encode("utf-8")
    if len(encoded) <= max_bytes:
        return text, 0
    return encoded[:max_bytes].decode("utf-8", errors="ignore"), len(encoded)
```

```python
"""Log lines as compact text: one header per stream (labels shared by every stream once, at the top), then a
millisecond timestamp and the line text. A line that is cut says so; notes say what was left out and how to narrow.
"""

from __future__ import annotations

from datetime import UTC, datetime

from ratatoskr.backends.loki.api import LINES_HINT, Direction
from ratatoskr.backends.loki.streams import LogLine, Stream, StreamsResult
from ratatoskr.backends.output import BlockWriter, clip_bytes, truncation_note
from ratatoskr.backends.series import series_name
from ratatoskr.backends.timeparse import TimeRange, format_time

LABELS_BYTES = 1024  # a stream header (labels after | json can be many) is cut to this
_NS = 1_000_000_000


def stamp(ns: int, *, same_day: bool) -> str:
    """``10:00:00.123`` when the window is within one day, else ``11-22T10:00:00.123`` (UTC)."""
    seconds, rest = divmod(ns, _NS)
    moment = datetime.fromtimestamp(seconds, UTC)
    return moment.strftime("%H:%M:%S" if same_day else "%m-%dT%H:%M:%S") + f".{rest // 1_000_000:03d}"


def line_text(line: LogLine, *, same_day: bool) -> str:
    """``  <time> <text>``; lines inside a multi-line entry are indented under the text."""
    prefix = f"  {stamp(line.ns, same_day=same_day)} "
    body = line.text.replace("\r\n", "\n").rstrip("\n").replace("\n", "\n" + " " * len(prefix))
    if line.cut:
        body += f" … [cut: {line.size} bytes]"
    return prefix + body


def common_labels(streams: list[Stream]) -> dict[str, str]:
    """The label pairs every stream has; empty for a single stream (its header shows all of them)."""
    if len(streams) < 2:
        return {}
    first, rest = streams[0].labels, streams[1:]
    return {key: value for key, value in first.items() if all(other.labels.get(key) == value for other in rest)}


def _ordered(streams: list[Stream], direction: Direction) -> list[Stream]:
    """Streams in the order of their first line: newest first for backward, oldest first for forward."""
    return sorted(streams, key=lambda stream: stream.lines[0].ns, reverse=direction == "backward")


def _plural(count: int, word: str) -> str:
    return f"{count} {word}" if count == 1 else f"{count} {word}s"


def format_streams(
    result: StreamsResult,
    *,
    window: TimeRange,
    direction: Direction,
    limit: int,
    max_lines: int,
    budget: int,
) -> tuple[str, int]:
    """Text and number of lines shown."""
    span = f"from {format_time(window.start)} to {format_time(window.end)}"
    if result.total == 0:
        return (
            f"No log lines {span}. Check the stream selector with loki_labels and loki_label_values, or widen "
            "the time range.",
            0,
        )
    streams = _ordered(result.streams, direction)
    shared = common_labels(streams)
    order = "newest first" if direction == "backward" else "oldest first"
    header = (
        f"{_plural(result.total, 'log line')} in {_plural(len(streams), 'stream')} {span}, {order} (times are UTC)."
    )
    if shared:
        header += f"\nLabels on every stream: {clip_bytes(series_name(shared), LABELS_BYTES)}"
    same_day = window.start.date() == window.end.date()
    writer = BlockWriter(budget)
    writer.add(header)
    shown = cut = 0
    for stream in streams:
        added, added_cut, complete = _add_stream(writer, stream, shared, same_day=same_day)
        shown += added
        cut += added_cut
        if not complete:
            break
    notes = truncation_note(shown, result.total, limit, unit="log lines", hint=LINES_HINT)
    notes += limit_note(result.total, limit=limit, max_lines=max_lines, direction=direction)
    if cut:
        verb = "was" if cut == 1 else "were"
        notes += (
            f"\n\n[{_plural(cut, 'line')} {verb} longer than this connection's line limit and {verb} cut (marked "
            '"[cut: N bytes]"). Select the part you need with | json, | logfmt or | line_format.]'
        )
    return writer.text() + notes, shown


def _add_stream(
    writer: BlockWriter, stream: Stream, shared: dict[str, str], *, same_day: bool
) -> tuple[int, int, bool]:
    """The stream's lines until the budget is spent: lines added, how many of them were cut, whether all fit.
    The header travels with the first line, so a stream never ends up as a header without lines."""
    own = {key: value for key, value in stream.labels.items() if key not in shared}
    title = f"{clip_bytes(series_name(own), LABELS_BYTES)} ({_plural(len(stream.lines), 'line')})"
    added = cut = 0
    for index, line in enumerate(stream.lines):
        text = line_text(line, same_day=same_day)
        if not writer.add(f"\n{title}\n{text}" if index == 0 else text):
            return added, cut, False
        added += 1
        cut += int(line.cut)
    return added, cut, True


def limit_note(total: int, *, limit: int, max_lines: int, direction: Direction) -> str:
    """When Loki stopped at the limit, more lines may exist in the window: say which ones and how to get them."""
    if total < limit:
        return ""
    missing = "older" if direction == "backward" else "newer"
    more = f", or pass a higher limit (at most {max_lines})" if limit < max_lines else ""
    return (
        f"\n\n[Loki stopped at the limit of {limit} lines: {missing} lines in this window were not returned. "
        f'Narrow the query (a shorter time range, more label matchers, a |= "text" line filter){more}.]'
    )
```

```python
"""loki_query: check the arguments, resolve the window (capped before any request), call query_range and format
the answer by its type: log lines (``streams``) or a metric query (``matrix``, the Prometheus format)."""

from __future__ import annotations

import asyncio
from datetime import timedelta
from typing import Any

from ratatoskr.backends.errors import BackendQueryError, InvalidRequestError
from ratatoskr.backends.limits import clip_input
from ratatoskr.backends.loki.api import SERIES_HINT, SOURCE, Direction
from ratatoskr.backends.loki.backend import LokiBackend
from ratatoskr.backends.loki.formatting import format_streams
from ratatoskr.backends.loki.streams import parse_streams
from ratatoskr.backends.output import response_budget, with_notes
from ratatoskr.backends.series import parse_result
from ratatoskr.backends.summarize import format_matrix
from ratatoskr.backends.timeparse import (
    TimeRange,
    format_duration,
    format_time,
    point_count,
    resolve_range,
    resolve_step,
    step_seconds,
    unix_seconds,
)
from ratatoskr.config.loki_models import LokiLimits
from ratatoskr.tools.runtime import ToolOutput

DEFAULT_LIMIT = 100  # lines per call unless the caller asks for more (up to limits.max_lines)
NO_DATA = "No series had data in this window: check the stream selector with loki_labels and loki_label_values."


def check_logql(logql: str, limits: LokiLimits) -> str:
    text = logql.strip()
    if not text:
        raise InvalidRequestError(
            'logql is empty: pass a LogQL query such as {app="api"} |= "error" or '
            'sum by (level) (count_over_time({app="api"}[5m])).'
        )
    if len(logql) > limits.max_query_length:
        raise InvalidRequestError(
            f"logql is {len(logql)} characters long; the limit for this connection is {limits.max_query_length}."
        )
    return text


def check_limit(limit: int | None, limits: LokiLimits) -> int:
    if limit is None:
        return min(DEFAULT_LIMIT, limits.max_lines)
    if not 1 <= limit <= limits.max_lines:
        raise InvalidRequestError(
            f"limit must be between 1 and {limits.max_lines} on this connection (got {limit}). To see other lines, "
            'narrow the query: a shorter time range, more label matchers or a |= "text" line filter.'
        )
    return limit


async def query(
    backend: LokiBackend,
    logql: str,
    *,
    start: str | None,
    end: str | None,
    limit: int | None,
    direction: Direction | None,
    step: str | None,
) -> ToolOutput:
    limits = backend.limits
    text = check_logql(logql, limits)
    lines = check_limit(limit, limits)
    order: Direction = direction or "backward"
    window = resolve_range(start, end, now=backend.now(), max_range=limits.max_range)
    chosen = resolve_step(step, window.span, max_points=limits.max_points)
    result = await backend.api.query_range(
        text,
        start=unix_seconds(window.start),
        end=unix_seconds(window.end),
        limit=lines,
        direction=order,
        step=step_seconds(chosen),
    )
    budget = response_budget(limits.max_response_bytes)
    kind = _result_type(result.data)
    if kind == "streams":
        parsed = await asyncio.to_thread(
            parse_streams, result.data, max_lines=lines, max_line_bytes=limits.max_line_bytes
        )
        body, shown = format_streams(
            parsed, window=window, direction=order, limit=lines, max_lines=limits.max_lines, budget=budget
        )
    elif kind == "matrix":
        body, shown = await _metric(result.data, window, chosen, limits, budget)
    else:
        raise BackendQueryError(f"Loki answered with a {clip_input(kind, 20)} result, which loki_query cannot show.")
    return ToolOutput(text=with_notes(body, result.notes, source=SOURCE, omitted=result.omitted_notes), rows=shown)


async def _metric(data: Any, window: TimeRange, chosen: timedelta, limits: LokiLimits, budget: int) -> tuple[str, int]:
    parsed = await asyncio.to_thread(parse_result, data, max_series=limits.max_series)
    expected = point_count(window.span, chosen)
    header = (
        f"matrix: {parsed.total} series from {format_time(window.start)} to {format_time(window.end)}, "
        f"step {format_duration(chosen)} (up to {expected} points per series; times are UTC)"
    )
    return format_matrix(
        parsed,
        header=header,
        expected=expected,
        same_day=window.start.date() == window.end.date(),
        max_series=limits.max_series,
        budget=budget,
        hint=SERIES_HINT,
        no_data=NO_DATA,
    )


def _result_type(data: Any) -> str:
    kind = data.get("resultType") if isinstance(data, dict) else None
    if not isinstance(kind, str):
        raise BackendQueryError("Loki returned a result in a shape Ratatoskr cannot read.")
    return kind
```

```python
"""loki_labels and loki_label_values: label names and values on streams with data in a window (default last hour),
optionally only on streams matching a selector."""

from __future__ import annotations

from typing import Any

from ratatoskr.backends.errors import BackendQueryError, InvalidRequestError
from ratatoskr.backends.limits import clip_input
from ratatoskr.backends.loki.api import SOURCE, VALUES_HINT
from ratatoskr.backends.loki.backend import LokiBackend
from ratatoskr.backends.output import BlockWriter, response_budget, truncation_note, with_notes
from ratatoskr.backends.series import LABEL_NAME_RE
from ratatoskr.backends.timeparse import TimeRange, format_time, resolve_range, unix_seconds
from ratatoskr.config.loki_models import LokiLimits
from ratatoskr.tools.runtime import ToolOutput


def check_selector(selector: str | None, limits: LokiLimits) -> str | None:
    if selector is None or not selector.strip():
        return None
    if len(selector) > limits.max_query_length:
        raise InvalidRequestError(
            f"selector is {len(selector)} characters long; the limit for this connection is {limits.max_query_length}."
        )
    return selector.strip()


async def list_labels(backend: LokiBackend, *, selector: str | None, start: str | None, end: str | None) -> ToolOutput:
    limits = backend.limits
    chosen = check_selector(selector, limits)
    window = resolve_range(start, end, now=backend.now(), max_range=limits.max_range)
    result = await backend.api.labels(selector=chosen, start=unix_seconds(window.start), end=unix_seconds(window.end))
    names = _strings(result.data)
    scope = _scope(chosen, window)
    if not names:
        return ToolOutput(text=f"No labels on streams {scope}. Widen the time range or loosen the selector.", rows=0)
    text, shown = _listing(f"{len(names)} label names on streams {scope}:", names, limits, unit="labels")
    return ToolOutput(text=with_notes(text, result.notes, source=SOURCE, omitted=result.omitted_notes), rows=shown)


async def label_values(
    backend: LokiBackend, *, label: str, selector: str | None, start: str | None, end: str | None
) -> ToolOutput:
    limits = backend.limits
    name = label.strip()
    if not LABEL_NAME_RE.match(name):
        raise InvalidRequestError(
            f"Invalid label name '{clip_input(label)}': use letters, digits and underscores, e.g. app, namespace or "
            "level; loki_labels lists the names."
        )
    chosen = check_selector(selector, limits)
    window = resolve_range(start, end, now=backend.now(), max_range=limits.max_range)
    result = await backend.api.label_values(
        name, selector=chosen, start=unix_seconds(window.start), end=unix_seconds(window.end)
    )
    values = _strings(result.data)
    scope = f'of label "{name}" on streams {_scope(chosen, window)}'
    if not values:
        return ToolOutput(
            text=f"No values {scope}. The label may not exist on streams with data in this window.", rows=0
        )
    text, shown = _listing(f"{len(values)} values {scope}:", values, limits, unit="values")
    return ToolOutput(text=with_notes(text, result.notes, source=SOURCE, omitted=result.omitted_notes), rows=shown)


def _listing(header: str, items: list[str], limits: LokiLimits, *, unit: str) -> tuple[str, int]:
    writer = BlockWriter(response_budget(limits.max_response_bytes))
    writer.add(header)
    for item in items[: limits.max_values]:
        if not writer.add(item.replace("\n", "\\n")):
            break
    shown = writer.kept - 1
    return writer.text() + truncation_note(shown, len(items), limits.max_values, unit=unit, hint=VALUES_HINT), shown


def _strings(data: Any) -> list[str]:
    """Loki leaves ``data`` out when the list is empty."""
    if data is None:
        return []
    if not isinstance(data, list):
        raise BackendQueryError("Loki returned a list in a shape Ratatoskr cannot read.")
    return [str(item) for item in data]


def _scope(selector: str | None, window: TimeRange) -> str:
    matching = f"matching {selector} " if selector else ""
    return f"{matching}with data between {format_time(window.start)} and {format_time(window.end)}"
```

```python
"""Register the three Loki tools (spec 6.4). Every tool goes through ToolRuntime.run with read access."""

from __future__ import annotations

from collections.abc import Awaitable, Callable
from typing import Annotated, Any, Literal

from mcp.server.fastmcp import FastMCP
from mcp.types import CallToolResult, ToolAnnotations
from pydantic import Field

from ratatoskr.backends import errors
from ratatoskr.backends.base import Backend
from ratatoskr.backends.loki import descriptions as d
from ratatoskr.backends.loki import discovery, querying
from ratatoskr.backends.loki.backend import LokiBackend
from ratatoskr.config.models import Access
from ratatoskr.tools.runtime import ToolOutput, ToolRuntime

ConnectionArg = Annotated[str, Field(description=d.CONNECTION)]
LogqlArg = Annotated[str, Field(description=d.LOGQL)]
StartArg = Annotated[str | None, Field(description=d.START)]
EndArg = Annotated[str | None, Field(description=d.END)]
LimitArg = Annotated[int | None, Field(description=d.LIMIT)]
DirectionArg = Annotated[Literal["backward", "forward"] | None, Field(description=d.DIRECTION)]
StepArg = Annotated[str | None, Field(description=d.STEP)]
SelectorArg = Annotated[str | None, Field(description=d.SELECTOR)]
LabelArg = Annotated[str, Field(description=d.LABEL)]

Call = Callable[[LokiBackend], Awaitable[ToolOutput]]


def _loki(backend: Backend) -> LokiBackend:
    if not isinstance(backend, LokiBackend):
        raise errors.InvalidRequestError(f"Connection '{backend.name}' is not a Loki connection.")
    return backend


def _read_only(title: str) -> ToolAnnotations:
    return ToolAnnotations(
        title=title, readOnlyHint=True, destructiveHint=False, idempotentHint=True, openWorldHint=False
    )


def register_loki_tools(mcp: FastMCP[Any], runtime: ToolRuntime) -> None:
    async def run(tool: str, connection: str, call: Call, query_text: str | None = None) -> CallToolResult:
        async def wrapped(backend: Backend, access: Access) -> ToolOutput:
            loki = _loki(backend)
            async with loki.deadline():  # one deadline for all requests of the call
                return await call(loki)

        result = await runtime.run(
            tool=tool,
            connection=connection,
            need=Access.READ,
            call=wrapped,
            query_text=query_text,
            kind=LokiBackend.kind,
            truncation_hint=d.TRUNCATION_HINT,
        )
        return result.to_call_tool_result()

    async def loki_query(
        connection: ConnectionArg,
        logql: LogqlArg,
        start: StartArg = None,
        end: EndArg = None,
        limit: LimitArg = None,
        direction: DirectionArg = None,
        step: StepArg = None,
    ) -> CallToolResult:
        return await run(
            "loki_query",
            connection,
            lambda backend: querying.query(
                backend, logql, start=start, end=end, limit=limit, direction=direction, step=step
            ),
            logql,
        )

    async def loki_labels(
        connection: ConnectionArg, selector: SelectorArg = None, start: StartArg = None, end: EndArg = None
    ) -> CallToolResult:
        return await run(
            "loki_labels",
            connection,
            lambda backend: discovery.list_labels(backend, selector=selector, start=start, end=end),
            selector,
        )

    async def loki_label_values(
        connection: ConnectionArg,
        label: LabelArg,
        selector: SelectorArg = None,
        start: StartArg = None,
        end: EndArg = None,
    ) -> CallToolResult:
        return await run(
            "loki_label_values",
            connection,
            lambda backend: discovery.label_values(backend, label=label, selector=selector, start=start, end=end),
            selector,
        )

    tools = (
        (loki_query, d.LOKI_QUERY, _read_only("LogQL query")),
        (loki_labels, d.LOKI_LABELS, _read_only("List log labels")),
        (loki_label_values, d.LOKI_LABEL_VALUES, _read_only("List log label values")),
    )
    for fn, description, hints in tools:
        mcp.add_tool(fn, description=description, annotations=hints, structured_output=False)
```

```python
def loki_sample_streams(now_ns: int) -> list[dict[str, Any]]:
    """Three streams for tenant LOKI_TENANT, all within the last 30 seconds before *now_ns*."""
    second = 1_000_000_000

    def at(seconds_ago: int, line: str) -> list[str]:
        return [str(now_ns - seconds_ago * second), line]

    return [

            "stream": {"app": "api", "level": "error", "pod": "api-1"},
            "values": [at(i + 1, f"error {i} GET /orders 500") for i in range(5)],
        },

def seed_loki(url: str, *, timeout: float = 60.0) -> None:
    """Push the sample streams through the push API, then block until all 11 lines can be queried."""
    headers = {"X-Scope-OrgID": LOKI_TENANT}
    deadline = time.monotonic() + timeout
    with httpx.Client(base_url=url, timeout=5.0, trust_env=False) as client:
        pushed = client.post(
            "/loki/api/v1/push", json={"streams": loki_sample_streams(time.time_ns())}, headers=headers
        )
        pushed.raise_for_status()
        while time.monotonic() < deadline:
            end = time.time() + 1
            answer = client.get(
                "/loki/api/v1/query_range",
                params={"query": '{level=~".+"}', "start": f"{end - 600:.3f}", "end": f"{end:.3f}", "limit": "100"},
                headers=headers,
            ).json()
            if sum(len(stream["values"]) for stream in answer["data"]["result"]) >= 11:
                return
            time.sleep(0.5)
    raise RuntimeError("Loki did not make the pushed lines queryable in time")
```
